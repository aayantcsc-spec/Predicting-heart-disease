The data problem

Two files. Only one of them contains a real signal.

Before modelling anything, I tested both datasets. The result decided the whole project.

Rejected

heart_disease_dataset.csv

500 rows, 19 columns, zero missing values — and its own README states it is synthetic. A Random Forest scores 0.458 ROC-AUC on it. That is worse than a coin flip. The generator drew each feature independently of the outcome, so there is genuinely nothing to learn.

Selected

UCI Heart Disease archive

920 real patients from Cleveland Clinic, Hungarian Institute of Cardiology, University Hospitals of Zurich and Basel, and the Long Beach VA. Messy, incomplete, collected in 1988 — and every relationship in it is real.

Why this matters for your write-up

Most student projects report 95% accuracy and stop. Showing that you tested and rejected a dataset is a stronger signal of competence than any accuracy number. Lead with this section.

Cohort

Four hospitals that disagree with each other

The archive is usually used as the 303-patient Cleveland file alone. Merging all four sites triples the sample — but introduces a problem worth studying rather than hiding.

Prevalence ranges from 36% in Hungary to 94% in Switzerland. These are not comparable populations. Switzerland's cohort was referred for angiography and is heavily selected; the Hungarian cohort is closer to a general cardiology clinic. Any model trained on one and deployed on another inherits that mismatch.

Missing data is not evenly spread

Two of the most clinically informative variables are also the least recorded.

Modelling

Six algorithms, one honest comparison

All six run inside the same scikit-learn pipeline, so imputation and scaling are fitted on training folds only — no leakage. Stratified 5-fold cross-validation on 75% of the data, then a single evaluation on the held-out 25%.

Finding

Random Forest reaches 0.912 ROC-AUC with 0.88 recall. In a screening context recall is the metric that matters: a missed case is a patient sent home with undiagnosed coronary disease, while a false positive costs one further test.

The real test

Train in Ohio, predict in Switzerland

A random train/test split flatters every model, because both halves are drawn from the same four hospitals. The harder question is whether a model trained at one hospital works at another it has never seen.

The conclusion that makes this a real project

A model reporting 0.91 AUC on a random split is not a model that works in a hospital. Same algorithm, same features — moved to a different patient population, it loses roughly half the cases it should catch.

This is the finding to build your presentation around. It reframes the work from "I trained a classifier" to "I measured where a classifier stops being trustworthy," which is the actual open problem in clinical machine learning.

Reproduce it

Running the analysis

The full pipeline is one file, roughly 260 lines, and runs in under a minute on a laptop. No GPU, no cloud.

# 1. Get the real data (not the synthetic Kaggle file)
from ucimlrepo import fetch_ucirepo
heart = fetch_ucirepo(id=45)

# or download all four sites directly:
# archive.ics.uci.edu/dataset/45/heart+disease

# 2. Run everything
python analysis.py

# Outputs:
#   heart_disease_merged.csv   920 patients, cleaned
#   model_results.csv          all six models scored
#   figs/                      10 publication-ready charts

What I would add next

  • SHAP values for individual patient explanations — turns "the model says 0.81" into "the model says 0.81 because of asymptomatic chest pain and ST depression of 2.3." That is the difference between a classifier and a clinical decision aid.
  • Leave-one-site-out cross-validation across all four sites, not just Cleveland, to get a proper distribution of the generalisation gap.
  • Threshold selection under an explicit cost ratio — state what a missed diagnosis costs relative to a false alarm, and derive the operating point from that rather than defaulting to 0.5.
  • Validation on a modern cohort. This data was collected in 1988. Treatment protocols, diagnostic criteria and population risk profiles have all shifted since.

Data — UCI Machine Learning Repository, Heart Disease Data Set (Detrano et al., 1989). Cleveland Clinic Foundation · Hungarian Institute of Cardiology, Budapest · University Hospitals Zurich and Basel · V.A. Medical Center, Long Beach.

Method — Python, scikit-learn, pandas, matplotlib. Median and mode imputation fitted within cross-validation folds. Stratified 75/25 split, 5-fold CV, permutation importance on held-out data.

Note — This is a portfolio and teaching analysis, not a clinical tool. It must not be used to inform any medical decision.
